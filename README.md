# Deepak Kumar — Portfolio

A responsive one-page portfolio inspired by the structure and minimalist developer aesthetic of the reference portfolio.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — reveal animations

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Go to Settings → Pages.
4. Choose “Deploy from a branch”, select the main branch and `/root`.
5. Save. GitHub will provide your live portfolio URL.

All personal details and project information were taken from the supplied CV. Education dates are kept as provided in the CV.
